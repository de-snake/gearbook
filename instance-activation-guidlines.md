# Instance Activation guidlines

### TL;DR (Actionable checklist)

1. Chain's block Gas Limit ≥ 30M
2. $GEAR address is either null or can be verified on block explorer to be $GEAR token correctly bridged from Ethereum
3. Wrapped Gas Token address is listed on Chain's docs as canonical&#x20;
4. Instance Owner Safe Proxy is deployed on target chain and can be verified on block explorer
5. Financial Multisig Safe Proxy is deployed on target chain and can be verified on block explorer

⚠️ If any of these criteria aren’t met: don’t sign, ask in chat for clarification.
